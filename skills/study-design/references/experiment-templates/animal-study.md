## 样本量计算（必须做）
- 效应量依据：[文献引用或预实验数据]
- α 与 power：[按设计选择并写理由]

- 计算工具：G*Power / R / `${CLAUDE_PLUGIN_ROOT}/skills/statistical-analysis/scripts/power_analysis.py`

## 分组与随机化
- 随机方法：随机数表 / 软件生成（必须说明）
- 分组时机：造模前 / 造模后
- 笼位：每笼混合分组（避免笼效应）
- 盲法：分组、给药、结局评估尽量由不同人完成

## 伦理与福利（IACUC）
- [ ] 伦理审查批准号
- [ ] 3R 原则说明（Replacement, Reduction, Refinement）
- [ ] 人道终点标准（写本模型的具体判定项目与阈值，以 IACUC 批准的方案为准；常见项目：体重下降、无法进食饮水、疼痛 / 痛苦评分）
- [ ] 麻醉方案（药物、剂量、给药方式）
- [ ] 镇痛方案
- [ ] 安乐死方法（须符合 AVMA 指南）
