# Module A — Clinical Research（临床研究）

> **本模块是必须覆盖的清单，不是填空表：按本研究的实际情况写；不适用的条目写"不适用 + 理由"；禁止照抄示例中的数字、例数和措辞。**

`study-design/SKILL.md` 的 Study Type Router 判定为 `type: clinical` 时读取本文件。
这里只放临床研究特有的判断；通用 Workflow（Step 0 分析真实条件 + Step 1–5）、Output、Hard Checkpoint、衔接规则都在 SKILL.md。

## 适用范围

RCT（含交叉、非劣效/等效、适应性、平台、实效性、群随机试验）、准实验、队列、病例对照、横断面、诊断准确性、预测模型、真实世界研究、注册研究。

## 研究类型决策树

```
研究问题
├── 评估干预效果？
│     ├── 可以随机？
│     │     ├── 标准平行组 → RCT（CONSORT 2025）
│     │     ├── 每个受试者接受所有干预 → 交叉试验（Crossover）
│     │     ├── 验证不差于标准疗法 → 非劣效/等效试验
│     │     ├── 中间分析调整设计 → 适应性试验（Adaptive）
│     │     ├── 多干预共享对照 → 平台试验（Platform）
│     │     ├── 真实临床环境 → 实效性试验（Pragmatic, PRECIS-2）
│     │     ├── 以科室/医院为随机单位 → 群随机试验（Cluster RCT）
│     │     └── 单个患者多次交替 → N-of-1 试验
│     └── 不能随机？ → 准实验（TREND）/ 队列
├── 探索暴露-结局关系？
│     ├── 前瞻性 → 前瞻性队列（STROBE）
│     ├── 回顾性 → 回顾性队列 / 病例对照
│     ├── 嵌套在队列中 → 巢式病例对照
│     └── 横断面 → 横断面研究
├── 利用已有真实世界数据？
│     ├── 电子病历/医保数据库 → 真实世界研究（RWE, RECORD）
│     └── 疾病注册数据库 → 注册研究（Registry Study）
├── 诊断/检测准确性？ → STARD
├── 预测模型？ → TRIPOD+AI（含传统回归模型）
├── 综合证据？ → 系统综述/Meta（PRISMA）→ 检索部分走 `literature-synthesis`
└── 描述性？ → 病例报告/系列（CARE）
```

决策树只列出可选的设计；选哪一个由 SKILL.md Step 0 的真实条件决定——"可以随机？"要看伦理、患者意愿和资源是否允许，"前瞻 / 回顾"要看数据从哪来、事件数够不够，而不是看哪种设计证据等级高。

## 特殊试验设计要点

| 设计 | 关键差异 | 样本量 | 报告规范 |
|------|---------|--------|---------|
| **交叉试验** | 洗脱期设计、期间效应、序列效应检验 | 通常比平行组少（同一受试者做对照） | CONSORT 交叉试验扩展（无本地清单，需人工核对） |
| **非劣效/等效试验** | 非劣效界值 Δ 的确定与依据是核心；单侧检验；**ITT 与 PP 均需报告，两者结论一致才可下非劣效结论**（ICH E9） | 通常比优效大（需排除 Δ） | CONSORT 非劣效/等效扩展（索引 `consort-noninferiority`） |
| **适应性试验** | 预设适应规则、alpha spending、独立数据监查委员会 | 分阶段计算 | ACE (CONSORT extension for adaptive designs, 2020)（无本地清单，需人工核对） |
| **平台试验** | 多臂共享对照、干预可进出、Master Protocol | 按臂计算 | 无统一规范，参考 CONSORT 2025 |
| **实效性试验** | PRECIS-2 评估实效性程度、宽纳入、真实环境 | 通常较大 | CONSORT 实效性试验扩展 + PRECIS-2（均无本地清单，需人工核对） |
| **群随机试验** | 随机单位 ≠ 分析单位；设计效应 = 1 + (m−1)·ICC | 个体样本量 × 设计效应 | CONSORT-Cluster |
| **准实验（非随机干预）** | 说明分组方式、控制混杂（PS/IPTW）、平行趋势假设 | 按效应量计算 | TREND |
| **真实世界研究** | 目标试验模拟（Target Trial Emulation）、混杂控制（PS/IPTW）、不朽时间偏倚 | 按效应量计算 | RECORD (STROBE extension) |
| **注册研究** | 数据完整性、随访丢失、变量定义标准化 | 通常为既有数据量 | STROBE / RECORD |

## 报告规范映射（与 `reporting-standards` 索引一致）

| 设计 | 结果论文 | protocol / 偏倚工具 |
|------|---------|-------------------|
| RCT | CONSORT 2025（30 项，含子项共 42 行） | SPIRIT 2025（34 项） |
| AI 干预 RCT | CONSORT 2025 + CONSORT-AI 2020 | SPIRIT 2025 + SPIRIT-AI 2020 |
| 群随机 / 非劣效 / 非随机干预 | CONSORT-Cluster / CONSORT 非劣效扩展 / TREND | SPIRIT 2025 |
| 队列 / 病例对照 / 横断面 | STROBE；外科 STROCSS；常规采集数据 RECORD | — |
| 诊断准确性 | STARD 2015 | QUADAS-2（评偏倚） |
| 预测模型 | TRIPOD+AI 2024 | PROBAST（评偏倚） |
| 病例报告 | CARE | — |
| 系统综述 / Meta | PRISMA 2020（+ PRISMA-S 检索报告） | PRISMA-P（PROSPERO 注册） |

## Protocol 关键判断

- 样本量用 `${CLAUDE_PLUGIN_ROOT}/skills/statistical-analysis/scripts/power_analysis.py` 或 G*Power；必须写明效应量来源（文献 / 预实验）、α、β、脱落率；生存结局按**事件数**而不是人数计算。
- 主要结局只有一个（或明确的共同主要结局），定义、测量方式、评估时点都写死；其余全部列为次要结局。
- 干预性研究必须在首例入组前注册（ClinicalTrials.gov / ChiCTR），注册号写进 protocol。
- 随机化（序列生成方式、分配隐藏）、盲法（谁盲、如何盲、无法盲时的替代措施）在 protocol 里逐项写清，不写"采用随机双盲"一句话带过。
- 详细 SAP → `data-analysis-planning`；伦理与注册核对 → `research-ethics`。

## Common Mistakes（临床特有）

| 想法 | 现实 |
|------|------|
| "样本量够大应该没问题" | 必须做正式 power analysis，并写明参数来源 |
| "纳入标准写宽一点好" | 过宽 = 异质性大 = 效应被稀释 |
| "横断面也能推因果" | 横断面只能看关联，不能推因果 |
| "非劣效试验做 PP 就够了" | ITT 与 PP 都要报告，结论一致才成立 |
| "先入组再注册也来得及" | 多数期刊拒收未在首例入组前注册的试验 |

## Convergence（临床特有完成条件）

1. 研究类型已确定且合理（对应决策树分支）
2. 样本量计算有明确依据（效应量来源、α、β、脱落率）
3. 纳入/排除标准具体可操作
4. 主要结局有明确定义与评估时点；次要结局已列出
5. 干预/暴露与对照/比较已定义（含随机化、分配隐藏、盲法方案，如适用）
6. 已识别主要混杂因素及控制方法
7. 报告规范已按上表选定

## Red Flags（临床特有）

- **禁止事后更换主要结局**（outcome switching = 学术不端）
- **禁止非劣效试验只报 PP 或只报 ITT**
- **禁止未注册即开始入组**（干预性研究）
- **禁止把"随机"写成"按就诊顺序交替分组"**（那是伪随机，分配隐藏失效）
