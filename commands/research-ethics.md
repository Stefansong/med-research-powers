# Research Ethics

Check ethical compliance and draft the Methods ethics statement.

Invoke the `research-ethics` skill, which contains the authoritative compliance checklist (IRB/IACUC, informed consent, data privacy, trial registration, COI & funding) and the Methods statement template. Pass through the user's study context: $ARGUMENTS

Note: this command is a reminder, not a hard block — the user is responsible for obtaining actual approvals. (Ethics compliance is Gate 5 of the `/pre-submission` 6-gate check.)
